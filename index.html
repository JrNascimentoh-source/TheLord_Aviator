Exemplos de distribuição das entradas
• R$ 7 + R$ 3 = uma entrada dentro dos 10%.
• R$ 5 + R$ 5 = uma entrada dentro dos 10%.
• Duas entradas de R$ 5: cada uma com R$ 3 + R$ 2.
A divisão é apenas um exemplo operacional. O valor da entrada não é contabilizado como lucro ou loss; o registro considera somente o resultado.
